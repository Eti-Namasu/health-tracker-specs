Health Tracker — streak widget (dots-only variant)

No numeric streak count is tracked or shown anywhere in this variant. The dot row and copy alone carry the motivation.

Rules for this variant

  1. The dot row is visible even before the user's very first log — it isn't gated behind a first action the way the previous version was.
  2. Dot states: green checkmark (logged), blank outlined circle (missed, past), blue "+" (the next actionable day — today, if unlogged), dashed outline (future, not yet reachable).
  3. Up to 2 consecutive missed days are tolerated: each renders as a blank dot, and the row continues normally with the "+" moving to today. A 3rd consecutive missed day resets the row.
  4. The tolerance is based only on the current run of consecutive misses — it resets to zero the moment the user logs again. A user can have many separate gaps over time (miss 2, log, miss 2, log...) without ever triggering a reset, as long as no single run reaches 3.
  5. A reset (3rd consecutive miss) restarts the row entirely: the next time the user logs, that day becomes the sole dot, no prior history shown, "+" only.
  6. No streak number is displayed anywhere. There is no "X day streak" text, and no fire icon tied to a numeric threshold.
  7. Reaching 7 green dots in a row is a celebratory milestone, marked with distinct copy (see below) since there's no number to point to.
  8. Decision: the row is a true rolling 7-day window (Alt A), not a cycle that resets every 7 days. Every day, the oldest dot scrolls off the left and a new "+" appears on the right for today. There is no "week 2" reset moment — progress is continuously visible.
