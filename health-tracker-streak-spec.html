Health Tracker — streak widget

All card states sketched so far, plus the rules governing them. Day numbers match the streak count (Day 1 = first log = 1 day streak).

Current rules (v1, simplified)

  1. The home card shows a 7-dot row: logged days are green checkmarks, today (if unlogged) is a blue "+", and days after today are dashed, non-interactive placeholders.
  2. Only one dot ever shows a "+" at a time — the next unlogged day. A logged day never keeps a "+"; a future day never gets one either, since it can't be logged yet.
  3. Reaching 7 green dots in a row completes a cycle, shown with celebratory copy. The streak count keeps climbing (8, 9, 10…) instead of resetting the number.
  4. Any single missed day resets the streak to 0 and the row restarts fresh the next time the user logs (no partial-week carryover). The first dot shows the last tracked day for context; today's "+" comes second.
  5. Day letters appear under each dot; today's letter is bolded for a redundant "you are here" cue.
  6. Users can backfill any missed date retroactively elsewhere in the app; the streak recalculates from actual logged dates.
  7. Once the streak reaches 7 days or more, a 🔥 appears next to the streak count.
  8. If the user goes 3 days in a row without opening the app to log at all, the card drops the dot row entirely and reverts to the plain prompt, same layout as the new-user card.
Still open / unconfirmed Should "your best streak" be shown anywhere on the reset states as encouragement, or kept fully clean like the new-user card?
