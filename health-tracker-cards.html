Health Tracker — card behaviour specs

No numeric streak count is tracked or shown anywhere in this variant. The dot row and copy alone carry the motivation.

Rules for this variant

  1. The dot row is visible even before the user's very first log.
  2. Dot states: green checkmark (logged), blank near-white circle (either a missed past day or a future day — visually identical, distinguished only by position relative to today), blue "+" (today, if unlogged).
  3. There is no reset mechanic. Missed days simply accumulate as blank dots, with no limit. The "+" always represents today and keeps moving forward one day at a time, no matter how long the user has been away.
  4. If a user has logged before but has no logs in the last 7 days, the row is laid out exactly like a brand-new user's (today's "+" first, 6 blank dots after), and the copy switches to a more re-engaging "long gap" variant. This is derived from the data on every render — it is not a stored reset event.
  5. No streak number is displayed anywhere. There is no "X day streak" text, and no fire icon tied to a numeric threshold.
  6. Reaching 7 green dots in a row is a celebratory milestone, marked with distinct copy (see below) since there's no number to point to.
  7. The row is a rolling 7-day window, not a cycle that resets every 7 days. Every day, the oldest dot scrolls off the left and a new "+" appears on the right for today. There is no "week 2" reset moment — progress is continuously visible.

The row is laid out exactly like a brand-new user's: today's "+" is the first dot, followed by 6 blank dots, with day letters starting from today. Only the copy differs, to reflect that this is a returning user. Nothing in the row looks back at the gap.
